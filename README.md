# Samuel Gomez da Silva

Qualidade, dados e testes de software. Há 4 anos trabalho para impedir que defeitos cheguem ao cliente final, e uso tecnologia para fazer isso melhor.

Sou Inspetor de Qualidade na OKEAN Yachts (Grupo Ferretti), onde respondo pelo ciclo completo de não conformidades: registro, análise de causa raiz, plano de ação, rastreamento até a correção e verificação do fechamento. Conduzi a migração do controle de RNCs de planilhas para um fluxo digital e participo do desenho do novo sistema de inspeções voltado à ISO 9001.

Curso Análise e Desenvolvimento de Sistemas na Univali (conclusão em 2027) e levo o mesmo raciocínio para o software: requisitos, casos de teste, automação e validação de dados.
